      About
      
        
      
          Structure-from-motion from a single webcam. There is no depth sensor involved, so the
          result is a sparse point cloud (plus an optional dense one on an NVIDIA GPU) with
          real-world scale only when the printed marker board was in view. Everything runs
          locally — nothing is uploaded.
